¿Qué es HTML5?

HTML5 es el lenguaje utilizado para crear y organizar la estructura de una página web.

Header

Representa el encabezado de una página o sección.

Nav

Contiene los enlaces principales de navegación.

Main

Agrupa el contenido principal de la página.

Footer

Representa el pie de página.

¿Qué es CSS?

CSS permite controlar la apariencia de una página web. Se utiliza para modificar colores, tamaños, márgenes, fondos, bordes y posiciones.

Diseño visual

Permite cambiar colores, fuentes, fondos y bordes.

Organización

Facilita la distribución de los elementos.

Diseño responsivo

Adapta la página a diferentes pantallas.
